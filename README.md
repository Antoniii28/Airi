# AIRI — Agente Inteligente para Acuarios Marinos

**Estado:** proyecto académico en fase de definición y documentación normativa. No se presentan funciones como implementadas ni certificaciones obtenidas.

AIRI se propone para analizar parámetros de un acuario marino, evaluar compatibilidad entre especies y, en una etapa posterior, sugerir la identificación de peces a partir de fotografías aportadas por el usuario. Las decisiones y acciones físicas permanecen bajo supervisión humana.

## Alcance de la actividad
Se documenta una **propuesta de normativa funcional y de seguridad**, con justificación y fuentes. La programación, validación de modelos y certificación quedan fuera de este entregable documental. Los requisitos técnicos deberán probarse antes de un despliegue real.

## Criterio normativo
- **Principal:** ISO/IEC 27001:2022 (seguridad de la información) e ISO/IEC 42001:2023 (gestión de IA).
- **Complementaria:** ISO/IEC 23894:2023 (orientación de riesgos de IA) y NIST AI RMF.
- **Condicional:** ISO/IEC 27701:2025 y legislación de protección de datos personales, según los datos que efectivamente se traten.

La consulta de fichas públicas ISO no equivale a estudiar sus textos completos ni acredita cumplimiento o certificación.
