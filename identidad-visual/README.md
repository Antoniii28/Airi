# Identidad visual de AIRI — Manual de marca (versión 1.0)

**Proyecto:** AIRI — Agente Inteligente para la Supervisión y Gestión de un Acuario Marino  
**Estado:** identidad visual propuesta a partir del boceto seleccionado por el equipo, 6 de noviembre de 2026.  
**Fuente visual:** [imagen original seleccionada por el equipo](AIRI_%20Pez%20Mascota%20Marino%20Tecnol%C3%B3gico.png) (pez tecnológico con visor, olas, circuitos y palabra AIRI). La imagen original es una composición rasterizada; **no debe presentarse como archivo vectorial editable**.

## 1. ¿Qué significa AIRI?

**AIRI** es el **nombre propio del agente inteligente** del proyecto, no una sigla con expansión letra por letra previamente establecida. Su descripción funcional completa es **«Agente Inteligente para la Supervisión y Gestión de un Acuario Marino»**. En el boceto seleccionado aparece el descriptor abreviado «Agente Inteligente para la Gestión de un Acuario Marino»; para los materiales institucionales se recomienda usar la denominación completa y consistente.

El nombre corto facilita recordarlo y utilizarlo en la interfaz, mientras que el descriptor explica su función: analizar parámetros del agua, orientar sobre compatibilidad de especies y, en una etapa futura, apoyar la identificación de peces por fotografía. **AIRI orienta; no sustituye las decisiones del responsable del acuario ni controla automáticamente equipos físicos en la versión inicial.**

## 2. Idea y personalidad de marca

**Concepto:** «El guardián inteligente del acuario».  
**Atributos:** observador, confiable, accesible, claro, tecnológico y respetuoso del entorno marino.

El personaje combina la forma reconocible de un pez con un visor de observación y un pequeño módulo electrónico. La expresión amigable comunica interacción sin convertirlo en una ilustración infantil. La marca busca un equilibrio entre tecnología y vida marina.

## 3. Significado del logotipo seleccionado

| Elemento visible | Interpretación para AIRI |
| --- | --- |
| Pez naranja y blanco | Identifica el entorno marino y las especies que el sistema ayuda a estudiar. |
| Visor azul/turquesa | Simboliza observación, análisis de imágenes y supervisión. |
| Ojos y sonrisa | Representan interacción clara y amigable con el usuario; no implican emociones reales del sistema. |
| Módulo lateral con conexiones | Evoca procesamiento de información e inteligencia artificial. |
| Pequeña antena o punto luminoso | Identifica al personaje como agente tecnológico, sin afirmar conexión inalámbrica real. |
| Olas bajo el pez | Representan el agua y las condiciones del acuario que AIRI analiza. |
| Burbujas | Refuerzan el ambiente submarino; pueden eliminarse en tamaños pequeños. |
| Circuitos alrededor de AIRI | Conectan el nombre con la tecnología y el análisis de datos. |
| Nombre AIRI | Identificador principal, breve y memorable. |

Estos significados son **interpretaciones de diseño propuestas para el proyecto**, no propiedades técnicas demostradas del software.

## 4. Paleta cromática de trabajo

La imagen contiene matices y degradados; por eso los códigos siguientes son **colores de referencia propuestos para reconstrucción vectorial**, no una extracción exacta de cada píxel.

| Nombre | HEX | Uso |
| --- | --- | --- |
| Azul marino | `#123B5D` | Nombre AIRI, contornos y texto principal. |
| Turquesa tecnológico | `#17B8C8` | Visor, conexiones y detalles de agua. |
| Naranja coral | `#F4A261` | Cuerpo, aletas y acentos. |
| Blanco | `#FFFFFF` | Fondo, rostro y espacios negativos. |
| Azul grisáceo muy claro | `#E8F3F7` | Fondos alternativos y áreas secundarias. |

**Uso recomendado:** azul marino dominante, turquesa como acento tecnológico y coral para reconocer al pez. Priorizar contraste y legibilidad; evitar añadir colores por decoración. Las variantes monocromáticas son obligatorias para aplicaciones de bajo contraste o impresión a una tinta.

## 5. Tipografía

La tipografía exacta del logotipo rasterizado **no puede identificarse con certeza solo por su apariencia**. Para reconstrucción en Figma se propone:

- **Nombre AIRI:** Sora Bold o Poppins Bold; mayúsculas, sans serif geométrica, peso fuerte, ajustes ópticos de espaciado.
- **Descriptor institucional:** Inter Medium o Nunito Sans SemiBold; legible, menos dominante que el nombre.
- **Textos de interfaz y documentación:** Inter Regular / Medium.

No afirmar que estas fuentes son las usadas en el archivo original. Comprobar licencias de las tipografías antes de distribuir archivos finales.

## 6. Composición y jerarquía

**Orden visual:** mascota > nombre AIRI > descriptor (opcional). Mantener proporciones y no estirar horizontal o verticalmente. El descriptor debe ser legible y omitirse en tamaños reducidos. En aplicaciones formales utilizar la frase completa **«Agente Inteligente para la Supervisión y Gestión de un Acuario Marino»**.

**Zona de seguridad propuesta:** dejar un margen libre alrededor de todo el logotipo igual, como mínimo, a la altura de la letra «I» de AIRI. Es una regla inicial que debe comprobarse durante la vectorización.

## 7. Variantes que deben producirse

1. **Principal vertical:** mascota, nombre AIRI y descriptor; portada y presentación.
2. **Horizontal:** mascota a la izquierda y nombre a la derecha; encabezado de la aplicación.
3. **Isotipo:** solo mascota simplificada, sin descriptor, circuitos externos ni burbujas; avatar y aplicación.
4. **Monocromática:** una sola tinta sobre fondo claro u oscuro.
5. **Negativo:** versión de alto contraste para fondo azul marino.

**Pruebas:** 512, 256, 64 y 32 píxeles. Si el módulo lateral o el visor dejan de reconocerse, simplificar trazos sin modificar la silueta principal.

## 8. Reglas de uso

**Permitido:** usar las variantes aprobadas, preservar márgenes, mantener la relación de aspecto, exportar PNG transparente y SVG cuando exista un vector real.

**Evitar:** alterar colores arbitrariamente, deformar el pez, usar fondos recargados, colocar el descriptor ilegible, añadir sombras 3D o elementos nuevos, afirmar que un PNG convertido automáticamente a SVG es un vector limpio, copiar los personajes de referencia originales.

## 9. Procedimiento de construcción en Figma

1. Importar la imagen seleccionada como **referencia bloqueada** en una página «Referencia original».
2. Crear una página «Reconstrucción vectorial» y dibujar silueta, aletas, visor, ojos, módulo tecnológico y ola con formas y trazados propios.
3. Definir estilos de color con los HEX de este manual.
4. Crear el texto AIRI con Sora/Poppins y comparar el peso visual con el boceto.
5. Generar componentes para mascota, logotipo vertical, horizontal e isotipo.
6. Simplificar detalles para tamaños pequeños; probar fondo blanco y azul marino.
7. Revisar con el equipo, registrar cambios y aprobar una versión.
8. Exportar SVG editable y PNG transparente; conservar el archivo fuente de Figma.

**Nota de originalidad:** el boceto se creó tomando ideas generales de referencias aportadas por el equipo; la reconstrucción final debe evitar copiar trazos o personajes ajenos.

## 11. Criterios de aceptación

- El nombre AIRI se lee claramente y el personaje se identifica como agente marino.
- Los colores coinciden con los estilos aprobados y tienen contraste adecuado.
- El isotipo funciona sin el texto y sigue siendo reconocible a 32 px.
- Las versiones tienen proporciones coherentes y fondos compatibles.
- Se cuenta con archivo vectorial verdaderamente editable antes de declarar terminada la identidad.
- El equipo aprueba la versión final y documenta la fecha de aprobación.
