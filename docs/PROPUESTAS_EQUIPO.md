# AIRI — Registro de ideas y mejoras del equipo

Este archivo es un **registro de propuestas**, no una lista de funcionalidades autorizadas ni terminadas. Conservar ideas aunque no se implementen de inmediato.

## Flujo
**Propuesta → En evaluación → Aprobada → Planificada → En desarrollo → Implementada**.

También puede terminar en **Descartada**, indicando motivo. El cambio de estado requiere decisión del equipo; no asumir aprobaciones.
