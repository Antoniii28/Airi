# AIRI — Hoja de ruta flexible

**Estado:** propuesta, no compromiso de entrega ni declaración de funcionalidades implementadas.

| Versión propuesta | Alcance previsto | Estado |
|---|---|---|
| v0.1 | Núcleo Python, entradas manuales/simuladas, validación, reglas de agua, alertas y recomendaciones explicables, pruebas | Por diagnosticar y planificar |
| v0.2 | Conocimiento documentado y evaluación de compatibilidad entre especies | Planificada, sujeta a revisión |
| v0.3 | API e interfaz web adaptable, basada en identidad visual de AIRI | Planificada, sujeta a revisión |
| v0.4 | Registro de acuarios, persistencia e historial | Planificada, sujeta a revisión |
| v0.5 | Identificación de peces mediante fotografías autorizadas y confirmación humana | Planificada, sujeta a revisión |
| v1.0 | Integración, pruebas y versión web estable | Objetivo futuro |
| v2.0 | Aplicación móvil conectada al mismo núcleo/API | Idea futura |

## Reglas del roadmap
- Las versiones son **orientativas**: el equipo puede reordenar, dividir, aplazar o añadir entregas.
- Las nuevas ideas se registran en [PROPUESTAS_EQUIPO.md](PROPUESTAS_EQUIPO.md), se evalúan y solo después se asignan a una versión.
- Ninguna idea se considera aprobada por aparecer aquí.
- Las funciones de versiones posteriores no se implementan automáticamente.
- En cada entrega se debe separar lo implementado, probado, parcial y pendiente.
- No confundir una página web adaptable con una aplicación móvil nativa.
- No confundir la detección de anomalías con el control automático del acuario.

**Próximo hito:** revisión del repositorio y aprobación del alcance de v0.1.
